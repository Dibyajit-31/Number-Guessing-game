<h1>Number Guessing Game 🎯</h1>

A fun command-line based number guessing game made using Python.<br><br>

The player has to guess a randomly generated number between <b>1 and 100</b> within a limited number of attempts based on the selected difficulty level.<br><br>

<hr>

<h2>Features ✨</h2>

- Random number generation<br>
- Multiple difficulty levels<br>
- Hint system<br>
- Replay option<br>
- Interactive terminal gameplay<br>
- Beginner-friendly Python project<br><br>

<hr>

<h2>Difficulty Levels 🎮</h2>

Easy ----- 20<br>
Moderate ----- 10<br>
Hard ----- 5<br>
Very Hard ----- 3<br>
Extreme ----- 2<br>

<hr>

<h2>How the Game Works 🕹️</h2>

1. Run the program<br>
2. Choose a difficulty level<br>
3. Guess the number<br>
4. Get hints after wrong guesses:<br>
&nbsp;&nbsp;&nbsp;&nbsp;- "The number is bigger..."<br>
&nbsp;&nbsp;&nbsp;&nbsp;- "The number is smaller..."<br>
5. Win by guessing the correct number within the allowed attempts<br><br>

<hr>

<h2>Technologies Used 💻</h2>

- Python 3<br>
- random module<br><br>
